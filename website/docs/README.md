## 维护规则

- 已确认的结论写入“已决定”，不要在后续讨论中重复假设。
- 尚未选择方案的内容写入“待讨论”，不提前实现。
- 明确不在当前阶段实施的内容写入“暂缓”。
- 每次形成新的结论时，补充日期、结论和主要理由；如果推翻旧结论，应保留变更背景。
- 与 Agent 协作时，同时遵守上一级的 [`AGENTS.md`](../AGENTS.md)。
