- **首次查询自动播种**: 标签列表为空时从现有笔记 tags 字段提取并批量插入

- **NoteMeta 重构**: 移除硬编码标签选项和 `type` 属性，schema 简化为 status/date/tags
- **删除标签**: Select 组件新增 `onDeleteOption`，下拉项悬停显示删除按钮
- **移除发布状态限制**: 去掉 `assertPublishInvariant`，任意状态的笔记均可发布
