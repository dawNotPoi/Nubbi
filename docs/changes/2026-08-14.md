### 变更摘要

### 变更摘要
- MCP_ALLOWED_HOSTS 留空时不再回退 localhost 白名单，而是完全不校验 Host 头（默认公开），便于开发测试直接远程访问；显式填写时白名单拦截照常生效（已实测：白名单实例对伪造 Host 返回 403，默认公开实例放行后由 Bearer token 鉴权兜底）。
- docker-compose 端口映射默认绑定 0.0.0.0（原 127.0.0.1），生产环境可在根 .env 设置 MCP_BIND_ADDRESS=127.0.0.1 收紧。
