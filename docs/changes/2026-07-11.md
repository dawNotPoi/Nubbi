# 2026-07-11

## feat(auth): 新增长期 API Token 鉴权管理

- **apiKey 插件**: `server/app/lib/auth.ts` 启用 better-auth 内置 apiKey 插件，`nb_` 前缀、SHA-256 哈希存储、默认永久有效、限流 300 次/分钟（插件默认仅 10 次/天）
- **关闭 session 伪造**: 显式设置 `disableSessionForAPIKeys: true`，杜绝带 x-api-key 的请求在 better-auth 端点伪造 session（否则可用 key 造 key、可触达注销接口）
- **新中间件**: `requireAuthWithApiKey`（middleware/session.ts）——带 `x-api-key` 走 `verifyApiKey` 解析 userId，否则回落原 session/JWT 逻辑；默认导出 `requireAuth` 不变
- **路由切换**: note/tag/file/meeting 四个业务路由改用新中间件（各一行 import）；`/auth` 敏感路由继续只认登录态
- **鉴权管理弹窗**: 新增 `ApiTokenModal.tsx`——Token 列表（掩码/创建时间/最后使用/过期时间）、创建（名称+有效期 30 天/90 天/1 年/永久）、一次性明文展示+复制、删除确认
- **入口**: SideBar 头像菜单「更换头像」与「退出登录」之间新增「鉴权管理」
- **客户端插件**: authClient 挂载 `apiKeyClient`，直接调 `/api/auth/api-key/*` 端点
- **对接文档**: 新增 `docs/api-token.md`（调用方式、接口清单、限流、博客/MCP 示例）
- **验证**: curl 全链路通过——token 访问数据按用户隔离、伪造/吊销/敏感接口均 401、Mongo 确认哈希存储、HTTP 层模拟 create/list/delete 流程通过
