# 首页模块 PRD

## 概述

登录后默认首页，展示最近笔记和近期会议。

**客户端**: `client/src/views/home/` — 路由 `/home`

## 页面组件

| 组件 | 文件 | 说明 |
|------|------|------|
| Home | `views/home/index.tsx` | 主页面 |
| RecentNoteList | `views/home/RecentNoteList.tsx` | 最近笔记列表 |
| RecentNoteCard | `views/home/RecentNoteCard.tsx` | 笔记卡片 |
| CardWrapper | `views/home/CardWrapper.tsx` | 卡片容器 |

## 数据来源

- 笔记：`GET /note/recent`
- 会议：`component/MeetingList/RecentMeeting`

## 使用组件

| 组件 | 来源 |
|------|------|
| Header | `component/Header.tsx` |
| RecentMeeting | `component/MeetingList/RecentMeeting` |

## 如何扩展

- 新增卡片：在 `views/home/` 添加组件，用 `CardWrapper` 保持风格一致
- 个性化：存偏好到 localStorage 或用户 meta

## 依赖

- note 模块（笔记数据）
- meeting 模块（会议数据）

## 移动端行为

- 手机保留独立列表与底部导航，笔记条目使用当前作者头像；桌面采用自适应网格。
- 近期会议按单列卡片展示，进入会议等主要操作在触摸设备上始终可见。
- 页面采用紧凑边距，并为固定底部导航和安全区预留空间。

## 桌面端视觉与操作（2026-09-29，已确认轻盈内容书架）

### 第二版：内容层次优化（用户确认）

- 首页展示最近五篇笔记；第一篇标记「继续编辑」，宽屏占两列，其余卡片各占一列。表示最近更新内容，不引入额外的阅读进度或最近访问记录。
- 去掉折角和顶部装饰条，减轻阴影；主卡使用极浅青绿底与细强调边，普通卡保持白色。
- 卡片正文最多显示两行真实内容摘录，纯文本展示，不生成摘要、不插入示例文案。复用账号隔离的详情查询缓存，仅为展示的五篇读取正文；加载失败显示「打开笔记查看内容」，空正文显示「还没有正文，继续写下你的想法」。
- 保留作者头像、时间、整卡键盘打开、手机独立列表及会议卡片。以下第一版的六篇和折角规则由本段覆盖。

- 视觉参考：`docs/ui/home-content-library-concept-2026-09-29.png`。标题为「我的空间」，说明为「收好想法，随时继续。」；右侧只放真实「新建笔记 / 上传文件 / 创建会议」，窄桌面允许工具栏换行。
- 最近编辑为首页主体，以两至三列自适应网格展示最近六篇笔记，整卡支持鼠标与键盘打开；「查看全部」进入笔记库，避免首页变成长篇内容清单。
- 卡片使用白色纸面、轻中性顶部条与折角，标题最多两行；底部恢复作者头像、名称和更新时间。最近笔记为当前账号内容，头像和名称复用当前用户资料，不伪造其他作者。
- 近期会议使用独立卡片区，放在最近编辑下方；白色卡片配淡紫日期区域，展示标题、起止时间、邀请和进入会议操作，标题旁「查看全部」进入会议页。无会议时使用紧凑卡片，引导使用顶部「创建会议」；加载和请求失败独立呈现，失败可重试。时间筛选沿用未来一周且未结束的规则。
- 新建笔记保留账号代次校验与提交中禁用；上传复用全局上传任务并展示进度面板；创建会议复用现有弹窗和校验。
- 首页作用域内采用青绿主动作、琥珀上传图标和淡紫会议提示，颜色数值集中在 theme.css；不改变其他模块的品牌色。卡片具备中性 hover、pressed 和清晰 focus，加载使用等尺寸骨架，失败有重试入口。
- 桌面侧栏顶部展示唯一的 NUBBI 品牌组合，账号入口固定在底部；账号菜单每个操作都提供清晰的悬停、焦点和点击反馈。
