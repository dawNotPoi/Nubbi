## 实测修正

- Better Auth 匿名 `/get-session` 的合法 JSON `null` 转为空会话，避免错误进入 unavailable。
- 普通后台 refresh 网络失败不清掉仍有效且未被拒绝的身份；首次/跨账号/401/退出确认仍严格区分。
- MongoDB 索引创建只传已定义选项，避免容器中 `undefined` 被序列化为 `null` 导致 CLI 失败。
- MCP Key 内部创建不再转发请求 headers，避免 SDK 将服务端 permissions 设置误判为外部调用；路由认证、可信 Origin 和 owner 来源不变。
