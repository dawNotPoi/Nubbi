## 2026-09-28 通用 API Token 接入（列表分页以上节补充为准）

本节替代下文历史 `/blog/*` 接入方案及其部署前提。用户确认由博客适配现有 Server，复用 Web「账户菜单 → 鉴权管理 → 通用 API」生成的 Token，不新增 Server 接口或 Web Token 类型。

- 博客服务端通过私有环境变量 `NUBBI_API_TOKEN` 读取 Token，以 `X-API-Key` 请求 `GET /note/all` 和 `GET /note/detail?noteId=...`；MCP Agent Token 只能访问 `/mcp-api`，不可混用。完整 Token 仅创建时显示一次，旧 Token 无法重新导出明文。现有通用 Token 具备完整账号能力，博客代码只执行这两个读取请求。
- Token 不进入公开站点配置、客户端代码、日志、页面或链接预览返回值。不转发读者 Cookie，不跟随上游重定向，不复制数据库凭据。
- 原始 Note 只在博客服务端存在；列表、详情、SEO 和站内预览共用适配层，仅展示 `published === true`、未删除且无密码的笔记。详情按当前响应再次检查，直接访问草稿／密码／删除文章的 ID 返回不可用；缺失／无效的公开标记不得放行。
- 响应以 `{code:1,data}` 校验；`_id` 映射为 id，日期回退 createdAt，标签去重，显式构造展示白名单。userId、password、层级、内部状态和任意 meta 不进入页面；meta 只提取字符串 excerpt。
- `/note/all` 当前最多返回最近更新的 500 条活跃笔记、不带正文。博客在已返回集合内做公开过滤、标题／标签字面搜索、排序与每页 10 篇分页，总数只代表该集合内可展示的文章，不能宣称覆盖整个账号。达到上限记录服务端提示；超过该范围的历史文章不能保证被列出，这是现有接口的已知限制。
- 列表摘要使用 meta.excerpt，没有则留空，避免逐篇读取正文；详情无显式摘要时从正文生成短摘要。详情 null 或 404 视为不存在，ID 不匹配或契约错误为 502。
- 缺少 Token 时记录配置提示：列表展示空数据、详情报告配置错误；401／403 不吞成空列表，便于发现失效或用途错误的 Token。既有连接失败／503／504 列表空态保留；请求使用 no-store，撤回后新请求重新校验。
- 远程真实联通还需要用户在博客本机或部署环境填入通用 Token；不在聊天中收集明文 Token，不自动创建凭证，不修改 Server 的鉴权或部署。

## API

统一响应：`{ code: 1, data, message }`，失败使用 `{ code: 0, message }`。

| 方法与路径 | 参数 | 返回 |
| --- | --- | --- |
| GET `/blog/posts` | offset ≥ 0，limit 1–50（默认 12），q ≤ 100 字，tag ≤ 50 字，order 为 newest / oldest / updated | 标准分页结果 items/total/count/limit/offset/hasMore/nextOffset |
| GET `/blog/tags` | 无 | 最多 100 个公开标签及文章计数 |
| GET `/blog/posts/:id` | 24 位十六进制 ObjectId | 公开文章与 Markdown 正文，不存在或不可公开时 404 |

列表字段：id、title、excerpt、tags、cover、author、date、updatedAt。
详情增加 content；日期采用 date、createdAt 顺序回退。
搜索按标题和标签进行字面匹配，正则元字符转义，查询限制执行时间。
默认使用 createdAt / _id 倒序；最早顺序改为升序，最近更新使用 updatedAt / _id 倒序，均保留稳定分页。

### 接口对接与运行（2026-09-22 实测）

- `NUBBI_API_URL` 是主服务 **API 基地址**，代码自行追加 `/blog/posts`、`/blog/tags`、`/blog/posts/:id`；不要写成以 `/blog` 结尾的地址。参数由 `URLSearchParams` 百分号编码，中文 `q` / `tag` 必须编码后发送。
- 本地开发：`pnpm dev:server` 后使用默认值 `http://localhost:4000`；线上：指向可公开访问的 API 地址（当前为 `http://dawnpoi.site:4000`，需保证该端口可达）。
- **部署前提**：主服务必须是包含 `/blog` 只读路由的版本。线上 `dawnpoi.site:4000` 当前仍是旧构建（`/blog/*` 返回 404、`/tag/list` 返回 401），需要先部署包含本模块的主服务；站点根域由 nginx 做 SPA 回退，不能当作 API 地址。
- 错误映射：列表/标签上游非 2xx 抛 `BlogApiError(status)`；响应不符合 `{code:1,data}` 契约视为 502；连接失败或 8 秒超时视为 503；详情 404 转为 Next 的 notFound，不渲染错误页。
- 实测（2026-09-22，主服务连测试库 `Nubbi`）：分页字段、`order` 校验（非法值 400）、`limit > 50` 拒绝、`/blog/tags` 结构、详情 404 行为均与上述契约一致；`published: true` 为零时列表返回空结果而非错误，空态由前端渲染。
- 前端渲染链路已用同契约真实响应验证：列表（标题/摘要/标签/日期/总数）、标签云与详情页 Markdown（标题、列表、行内代码、代码块）均正确渲染，服务端日志无 `BlogApiError`。
