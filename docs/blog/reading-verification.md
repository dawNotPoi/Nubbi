## 链接预览

- GitHub 和 Next.js 文档的真实标题、摘要读取成功；GitHub 仓库使用简短名称。
- 单独一段的 URL 生成卡片，作者提供的自定义标题保留。
- 行内链接提供预览按钮和浮层，原始链接仍可直接打开。
- 浮层按需挂载；卡片通过 IntersectionObserver 接近视口时才加载元数据。
- 同一外链并行请求 8 次只调用一次 fetch，缓存后继续复用。
- 20 个不同链接的请求检查中，并发峰值为 4。
- 连续两次站内预览均重新请求；撤回临时记录发布后预览立即 unavailable。
- 本地生产服务中，8 个已缓存摘要请求共耗时 37 ms；该值仅反映本机缓存命中，不代表外网抓取耗时。

## 抓取边界

- HTTP 响应仅含 title、description、siteName、available，设置 private/no-store。
- IPv4 私网、环回、链路本地、共享地址、保留地址、IPv6 私网与映射环回地址校验通过。
- 不支持的协议、凭据 URL、自定义端口与元数据地址不会被抓取。
- 连接使用已验证 IP，保留正确 Host 与 TLS 主机名；每次跳转重新校验。
- 抓取限制为 192 KiB、总超时 4.5 秒、3 次重定向；服务端最多并发 8 个外站抓取。
- 代理合成 DNS 环境通过固定公网 DNS 端点兼容，重新校验解析结果；可通过环境变量关闭。
- HTML 实体、Open Graph 标题优先级、正文伪造 meta 忽略与字段长度限制检查通过。
