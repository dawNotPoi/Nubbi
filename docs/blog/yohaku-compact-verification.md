# 余白紧凑文稿页验证

日期：2026-09-05。

## 视觉依据

用户明确指定 [innei.in/posts?view_mode=compact](https://innei.in/posts?view_mode=compact)
为当前参考，替代此前 Dawn / Shiro 宽松列表的演绎。
本次直接查看原站 PC、手机、首页和正文页面，读取 DOM 尺寸与字体，再独立实现 Nubbi 界面。

| 项目 | 原站测量 | Nubbi 当前实现 |
| --- | --- | --- |
| 1440px 列表容器 | 896px | 896px |
| 主列 / 侧栏 / 间隔 | 588 / 252 / 56px | 588 / 252 / 56px |
| 列表标题 | 28px，常规字重 | 28px，常规字重 |
| 条目标题 / 摘要 / 元信息 | 16 / 13 / 12px | 16 / 13 / 12px |
| 紧凑条目 | 约 99px，摘要单行 | 约 102px，摘要单行 |
| 页头 | 轻量居中导航 | 自有标识、居中博客导航 |
| 手机 | 搜索／标签入口与底部导航 | 同样布局，原生搜索／标签弹层 |
| 正文 | 宽栏、桌面居中标题、无外框 | 920px 文章区、约 872px 正文、独立轻目录 |

首页改为居中介绍、圆形自有标识和近期文章；背景为奶白、玫瑰暖色与少量细光点。
光点仅使用 CSS 透明度动画，可在页脚关闭；减少动态效果时完全隐藏。
没有复制原站代码、头像、文章或身份信息，也没有伪造置顶、评论和阅读量。

Instrument Sans 拉丁可变字体本地托管，文件 30,092 字节，使用 `font-display: swap`。
来源：[Google Fonts 字体目录](https://github.com/google/fonts/tree/main/ofl/instrumentsans)，
OFL 许可随字体保存在 `nubbi-blog/public/fonts/`。中文优先使用设备已有 MiSans，随后使用系统字体，
因此不同设备的中文字形仍可能与原站不同；不新增远程字体请求。

## 交互与数据

- 整条文章使用原生链接，保留键盘、新标签打开与按意图预取。
- 每页 10 篇；最新／最早／最近更新分别使用稳定的创建时间或更新时间排序。
- 搜索、标签、排序和页码通过 URL 保存，返回列表保留来源筛选。
- 右侧搜索／标签与手机弹层复用相同筛选组件；搜索弹层打开后自动聚焦输入框。
- 手机选择标签或提交搜索后关闭弹层；Esc、焦点恢复和滚动解锁沿用统一对话框 hook。
- 正文保留链接摘要、图片放大、章节跳转与阅读偏好；链接卡片收至最大 560px 并居中。
- Nubbi 数据库、连接凭据与公开条件不变，没有写入样式演示数据。
