# Yohaku 设计语言与移动阅读验证

> 历史视觉验证记录；当前主题和布局已由 [Shiro 暖色设计验证](./shiro-design-verification.md) 替代。

日期：2026-09-05。

## 参考与设计决定

- 参考 [Yohaku 公开设计系统](https://yohaku.innei.dev/) 与 [在线站点](https://innei.in/)。
- 参考仓库提交：`f31a1a1f5420f6f69f91639b65ad4453f1074220`。
- 独立实现文字优先的页面：暖白纸面、三级中性色、绿色强调、衬线标题与系统字体回退链。
- 首页采用 800px 单列文章流；文章采用约 680px 正文和桌面目录侧栏。搜索列表不重复首页介绍。
- 颜色只在 `theme.css` 定义，字体、尺寸、间距与动效参数扩展现有 token。
- 无新增依赖、外部字体下载或第三方 Web 源码导入。

## 浏览器验证

- 桌面 1440×900、平板 768×1024、手机 390×844，以及窄屏 320×740 检查通过。
- 真实后端当前无公开文章；有内容的列表和长文通过独立 4001 端口的临时响应验证，未写入演示文章。
- 首页、列表、搜索无结果、长标题、标签导航与正文未出现页面横向溢出；代码和表格保留独立滚动区。
- 390px 首页第一篇文章起点约为 559px，首屏可直接看到文章内容；手机搜索输入为 16px。
- 手机目录可打开、Esc 关闭、选章节后关闭并定位，焦点和页面滚动正常恢复。
- 打开目录自动显示当前章节；窗口切回桌面时关闭手机抽屉并解除滚动锁。
- 长文中段切换 17px／20px 字号后仍为相同章节，观测段落位置偏移小于 1px。
- 宋体／黑体、浅色／深色切换成功，刷新后恢复所选字号、字体和主题。
- 链接预览、真实 GitHub 摘要、图片放大与 Esc 关闭完成回归检查。
- 从关键词和标签筛选结果进入文章，返回地址同时保留 q 与 tag。
- 浏览器未发现 error/warn；未在实体 iOS 或 Android 设备上进行验证。

## 工程与可访问性

- 博客 ESLint、类型检查、Next.js 生产构建通过。
- 未新增或修改自动化测试文件；偏好校验、同步和存储失败路径通过终端临时执行验证。
- 偏好快照稳定，SSR 使用默认值；首屏脚本仅接受白名单值，存储不可用时仍可操作当前页面。
- 页面普通文字与强调文字对背景的计算对比度：亮色最低 4.81:1，深色最低 7.05:1。
- 保留可见键盘焦点和减少动态效果；目录与图片共用原生对话框生命周期。
- 源文件不超过 200 行，无组件颜色字面量和未定义 CSS 变量。

## 视觉复查后的修正

- 桌面主题标签改为自动换行，手机仍可横向选择。
- 首页标题在手机按语义分行，避免句子在不自然的位置断开。
- 链接卡片使用功能字体，避免继承正文宋体后英文摘要难以扫描。
- 修正调大字号导致阅读位置偏移，以及辅助文字对比度不足的问题。
