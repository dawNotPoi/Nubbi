## 运行时规则

- 使用同一 BrandLogo 入口渲染品牌，不使用旧金色 Sparkles 或人物头像代替 Logo。
- 插画仅在桌面认证布局需要时请求；手机不能只用 display:none 隐藏仍下载的大图。
- 图片声明真实 width/height；图形缩放不变形。文本、表单、按钮必须是真实 DOM，不把产品稿当背景覆盖整个页面。
- 普通导航仍用 Lucide，用户头像仍代表用户身份。
- 文件导入已校验每个分块 Git SHA、完整 SHA256、字节数和 WebP 容器。临时导入脚本已删除，运行时没有分块依赖。
